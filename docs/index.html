Patient-Aware Explainable Machine Learning for Breast MRI Radiomics

This project develops a patient-aware machine-learning framework for classifying benign and malignant breast lesions using quantitative MRI radiomic features. The study evaluates whether selective integration of multiple MRI sources can improve classification in high-dimensional, small-cohort settings. Five MRI-derived radiomic sources were systematically evaluated across 31 source configurations, comparing feature-selection strategies, class-balancing methods, and ten machine-learning classifiers using patient-aware nested cross-validation to ensure reliable performance estimation.

Study at a glance

Selective MRI feature fusion instead of “more is always better”

Multiparametric MRI provides complementary information from different imaging sequences, but combining all available features does not necessarily lead to better machine-learning models. Radiomic datasets typically contain hundreds of quantitative descriptors while being limited by the number of available patients, creating a risk of overfitting and unstable predictions. This study systematically investigates whether selective integration of MRI feature sources can improve classification of benign and malignant breast lesions compared with individual sources and complete feature concatenation.

Five MRI-derived radiomic sources were analysed independently and in every possible non-empty combination, resulting in 31 source configurations: five single-source datasets, ten pairwise combinations, ten triple-source combinations, five quadruple-source combinations, and one complete five-source dataset.

Research questions

Does MRI feature fusion improve classification?

The study evaluates whether combining complementary MRI sources improves predictive performance compared with single-source models and complete feature concatenation. All possible source combinations were tested rather than assuming that additional imaging information automatically improves classification.

How can reliable generalisation be achieved?

Radiomic studies often face a mismatch between a high number of extracted features and a limited number of patients. To reduce optimistic performance estimates, patient-aware validation and training-only preprocessing were used throughout model development.

Which machine-learning strategy performs best?

The study compares multiple modelling choices, including sequential feature-selection strategies, automatic feature-count optimisation, SMOTE-based class balancing, and ten different classifiers to identify robust modelling pipelines.

Methods

Patient-aware nested machine-learning framework

The complete analysis was designed to estimate realistic model generalisation while preventing information leakage. Since multiple regions of interest (ROIs) could originate from the same patient, all ROIs belonging to one patient were always assigned to the same validation partition. All data-dependent operations, including preprocessing, feature selection, feature-count optimization, and model tuning, were performed only using the corresponding training data within each cross-validation loop.

01

MRI radiomic feature sources

Five quantitative MRI feature sources were analysed: apparent diffusion coefficient (ADC), DCE pre-contrast (Pre), DCE post-contrast phases (Post1 and Post2), and T2-weighted MRI (T2W). Each source contained radiomic descriptors representing intensity, texture, and morphological characteristics.

02

Systematic source fusion

Instead of evaluating only individual modalities or complete concatenation, every non-empty combination of MRI sources was tested. This produced 31 datasets: 5 single-source, 10 pairwise, 10 triple-source, 5 quadruple-source, and 1 all-five-source configuration.

03

Patient-aware nested validation

Model development used a nested cross-validation framework. Five outer folds were used for unbiased performance estimation, while three inner folds were used for feature selection, hyperparameter optimization, and model development. Patient-level separation was maintained in all folds.

04

Feature reduction and selection

High-dimensional radiomic spaces were reduced using sequential feature-selection strategies. Three approaches were compared: correlation filtering followed by mRMR, Elastic Net followed by mRMR, and mRMR followed by Elastic Net. The number of retained features was automatically optimized within the training process.

05

Class imbalance handling

Synthetic Minority Over-sampling Technique (SMOTE) was evaluated as an optional training-only strategy. It was applied after feature selection and standardization so that synthetic samples could not influence feature selection or validation data.

06

Classifier optimization

Ten machine-learning classifiers were compared, including linear and nonlinear models. Classifier-specific hyperparameters were optimized using Optuna with a Tree-structured Parzen Estimator approach inside the inner cross-validation loop.

Results

Selective fusion outperformed complete MRI feature concatenation

Across all 31 MRI source configurations and thousands of machine-learning pipelines, the highest-performing model was not obtained by combining every available MRI sequence. Instead, a selective triple-source representation combining ADC, DCE-Post1, and DCE-Pre radiomic features achieved the strongest discrimination. This finding suggests that adding more feature sources can introduce additional variability and redundant information, while carefully selected complementary sources may provide a more robust representation for classification.

Model evaluation

Performance ranking was based on mean ROC-AUC across five patient-aware outer cross-validation folds. Final evaluation used unseen patient data through pooled out-of-fold predictions.

Generalisation performance

The selected model achieved a pooled ROC-AUC of 0.799, pooled PR-AUC of 0.832, and Brier score of 0.183, providing complementary discrimination and calibration measures.

Fusion level comparison

The best performance occurred at the triple-source level. Increasing the number of MRI sources beyond this point did not improve discrimination.

Explainability

Understanding model decisions through feature stability and SHAP

Radiomic models can achieve strong predictive performance while relying on large numbers of quantitative image features. To improve interpretability and assess whether the learned patterns were reliable, the highest-ranked model was analysed using two complementary approaches: feature-selection stability across validation folds and SHAP-based model interpretation. Feature stability evaluates whether the same features are repeatedly selected when the model is trained on different patient subsets, while SHAP analysis estimates how individual features contribute to model predictions.

28 unique features selected at least once across outer folds
13 features repeatedly selected in at least two outer folds

The selected features were mainly derived from ADC and DCE-Post1 radiomic sources. ADC first-order intensity descriptors showed high recurrence across folds and strong SHAP importance, indicating that diffusion-related intensity patterns contributed substantially to model predictions. Additional influential features included DCE-Post1 intensity, morphological characteristics, and texture descriptors, suggesting that complementary information from diffusion and contrast-enhanced MRI contributed to the final classification model.

Why feature stability matters

In high-dimensional radiomic datasets, a model may select different features depending on small changes in the training data. Features that repeatedly appear across independent patient splits provide stronger evidence of consistent model behaviour.

SHAP explains how features influence model predictions within the trained model. These explanations describe computational model behaviour and should not be interpreted as evidence of biological causation.
Publication

Manuscript, code, and reproducibility

This website accompanies the manuscript describing a systematic patient-aware machine-learning study for breast lesion classification using single- and multiparametric MRI radiomic features. The work evaluates MRI feature fusion strategies, feature-selection methods, class-balancing approaches, and multiple machine-learning classifiers within a rigorous validation framework.

Research use

Reproducible research framework, not a clinical device

The reported results represent internal patient-aware validation of computational models developed from MRI radiomic features. The framework demonstrates a reproducible machine-learning workflow, but clinical deployment requires independent external validation using larger and multicenter datasets.

Data and code availability

Source code for the computational pipeline is provided through the project repository. The imaging datasets may be available from the corresponding author upon reasonable request, subject to institutional, ethical, and privacy requirements.
